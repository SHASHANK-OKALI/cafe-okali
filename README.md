# ☕ OKALI'S CAFE

A modern, elegant and fully responsive cafe website built using **React.js, JavaScript, HTML, CSS and Bootstrap**.

OKALI'S CAFE is designed as a real-world cafe business website where customers can explore the menu, learn about the cafe, view beautiful moments through the gallery, read customer reviews, make table reservations and get in touch with the cafe.

## 📌 Project Overview

**OKALI'S CAFE** is a modern frontend web application created to demonstrate real-world business website development, responsive UI design and interactive frontend functionality.

The project focuses on creating a professional digital presence for a cafe while providing customers with an attractive and easy-to-use experience.

The website combines:

- Modern UI/UX design
- Responsive layouts
- Interactive components
- Smooth navigation
- Category-based menu filtering
- Table reservation interface
- Image gallery and lightbox
- Customer testimonials
- Contact information
- Premium cafe-inspired visual design
